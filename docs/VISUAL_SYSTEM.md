# Motion & Visual System — Codesphere Profile

## Intent
A cinematic, restrained engineering identity: graphite/navy canvas, ice-blue information, warm gold accents and confident editorial typography. The story of personal growth is conveyed through clear hierarchy and a six-stage engineering timeline.

## Tokens
- Canvas: `#050b16`, `#071020`
- Surface: `#0b1d33`
- Primary text: `#f0f7fe`
- Secondary text: `#9fb9d2`
- Information accent: `#7bd7ff`
- Achievement accent: `#e8b970`
- Borders: translucent ice blue, not opaque neon

## Motion
- 0.8–0.9s entrance transitions for key text elements.
- ~42–58s slow orbit effects to suggest systems engineering.
- Short path trace reveal for the engineering timeline.
- Respect `prefers-reduced-motion: reduce`; all essential text is visible without animation.
- SVG files contain no scripts, imported fonts or network dependencies.
- No flashing effects; use subtle, calm loops.

## GitHub constraints
GitHub profile READMEs support Markdown, limited HTML and image-based SVG or GIF. They do **not** run custom JavaScript applications or arbitrary interactive components. The rich interactive experience belongs in the separate `codesphere-portfolio` website. SVGs are presentation assets, not buttons; repository links are plain Markdown immediately below the image.

## Editorial rules
- Avoid unverified test-count and benchmark claims in high-level profile copy.
- Public cards link to actual public repositories.
- Describe Funa Gigs under Jaminsa Ventures Limited, separate from Codesphere Innovations.
- Preserve proper educational affiliation with ISBAT University.
- Maintain readability on narrow screens and accessible alternative text.
